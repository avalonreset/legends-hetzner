# Support

Use [GitHub issues](https://github.com/avalonreset/legends-hetzner/issues) for
module defects and feature requests. Include sanitized reproduction steps and
the exact module, Python, operating-system, and `hcloud` versions.

Hetzner billing, account access, regional capacity and provider incidents
belong to Hetzner support. Application deployment and Coolify administration
are separate concerns. This community project has no service-level agreement.
