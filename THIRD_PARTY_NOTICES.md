`legends-hetzner` is independent software by Benjamin Samar. It is not an
official Hetzner product and is not affiliated with or endorsed by Hetzner.

- [Hetzner Cloud CLI](https://github.com/hetznercloud/cli) supplies provider
  operations. It is maintained by Hetzner Cloud and contributors under the
  [MIT license](https://github.com/hetznercloud/cli/blob/main/LICENSE). The CLI
  is an external prerequisite; its executable and source are not bundled here.
- Python and its standard library supply the runtime. Python is distributed
  separately under the [Python license](https://docs.python.org/3/license.html).
- [cto-legends](https://github.com/avalonreset/cto-legends) supplies module
  discovery and installation. The vendored central router skill retains its
  upstream identity. [legends-empire](https://github.com/avalonreset/legends-empire)
  supplies the optional knowledge attachment transaction engine; it is not
  reimplemented or bundled here.
- Public references summarize and link to official documentation; they do not
  redistribute entire documentation sites.
- House artwork uses the owner's supplied Legends Regular font. The font
  file is not included. Rendered artwork does not grant a font license.

Coolify is an optional, separately installed application platform. Its
licensing and support belong to [Coolify](https://github.com/coollabsio/coolify).
No Coolify software is bundled in this module.
